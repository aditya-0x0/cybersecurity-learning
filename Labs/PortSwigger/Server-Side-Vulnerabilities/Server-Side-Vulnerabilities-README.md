## Key Learning Outcomes

- **Path Traversal:** Understanding how insecure file path handling can expose files outside an application's intended directory.
- **Access Control:** Understanding authorization weaknesses that may let users access resources or perform actions beyond their permissions.
- **Authentication:** Studying weaknesses in login and authentication mechanisms.
- **SSRF:** Understanding how server-side requests can be manipulated to reach unintended internal or external resources.
- **File Upload Vulnerabilities:** Learning how insufficient validation of uploaded files can introduce security risks.
- **OS Command Injection:** Understanding how unsafe handling of user input in operating-system commands can lead to command execution.
- **SQL Injection:** Studying how improperly handled database queries can allow interference with database operations.

## Practical Approach

I used hands-on lab exercises to study vulnerability behavior, investigate application responses, and understand how weaknesses can be identified and addressed.

My focus was on understanding the underlying security concepts rather than simply completing the labs.
