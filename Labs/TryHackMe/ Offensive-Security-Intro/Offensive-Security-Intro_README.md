## 📚 What I Learned

### 1. Offensive Security

Offensive security focuses on proactively finding weaknesses in systems before malicious attackers can exploit them.

A typical offensive security process can be represented as:

```text
Reconnaissance
      ↓
Enumeration
      ↓
Identify Weakness
      ↓
Exploit
      ↓
Validate Impact
      ↓
Report
```

The objective is not simply to "hack" a system, but to understand how a weakness could be abused and communicate the risk responsibly.

---

### 2. Ethical Hacking

Ethical hackers perform security testing with explicit authorization.

Important principles:

- Always have permission before testing.
- Stay within the defined scope.
- Avoid unnecessary damage.
- Do not access unrelated systems or data.
- Document findings responsibly.

TryHackMe provides an authorized environment where these concepts can be practiced safely.

---

### 3. Web Application Security

The practical portion of the room introduced the idea that web applications can contain weaknesses that allow unintended actions or information disclosure.

A security tester should approach a web application by asking:

```text
What does the application do?
        ↓
What inputs does it accept?
        ↓
How does it process those inputs?
        ↓
Can the behavior be manipulated?
        ↓
What is the security impact?
```

---

### 4. Practical Exploitation

The room provided a deliberately vulnerable website for the learner to interact with.

```text

       ↓

       ↓
Observe Response
       ↓

```

This helped connect offensive-security theory with an actual hands-on workflow.

## 🧠 Key Takeaways

- Offensive security focuses on identifying weaknesses proactively.
- Ethical hacking requires explicit authorization.
- Vulnerabilities can often be discovered by understanding application behavior.
- Practical labs are useful for developing an attacker's mindset safely.
- Exploitation should always be performed within an authorized scope.
- Finding a vulnerability is only part of the process; understanding impact and documenting it are also important.
