# 🗄️ SQL

SQL is a database query language used to interact with relational databases.

### Topics Covered

- Databases
- Tables
- Rows and columns
- Primary keys
- Foreign keys
- Relationships
- SELECT
- INSERT
- UPDATE
- DELETE
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate functions
- JOINs
- Subqueries
- Constraints
- Basic database design

### Cybersecurity Applications

SQL knowledge is important for understanding:

- Database security
- Application-to-database communication
- Access control
- Data exposure
- SQL injection concepts
- Secure database queries
- Web application security

SQL injection testing should only be performed against systems where explicit authorization exists.
